# R07-10 — 20 редакционных смысловых контрастов SAMA 0.14.0

Эти пары проверяют разграничение смыслов, а не результаты независимых испытуемых. Для каждой пары машинный тест требует два корректных разбора, разные леммы и разные дефиниции. Редакционные толкования ниже являются частью принятого словаря.

1. **холм / гора** (`halima` / `tano`): `Mi si halima.` ↔ `Mi si tano.`. Невысокая возвышенность не равна горе.
2. **климат / погода** (`kilima` / `wetala`): `Mi tami kilima.` ↔ `Mi tami wetala.`. Долгосрочный режим не равен состоянию атмосферы сейчас.
3. **семя / корень** (`semila` / `lamota`): `Mi si semila.` ↔ `Mi si lamota.`. Зародыш с запасом питания не равен вегетативному органу.
4. **кролик / лиса** (`labita` / `hokisa`): `Mi si labita.` ↔ `Mi si hokisa.`. Разные биологические животные.
5. **сыр / яйцо** (`kesina` / `ewana`): `Mi kula kesina.` ↔ `Mi kula ewana.`. Два самостоятельных вида пищи.
6. **кастрюля / сковорода** (`paneka` / `paniya`): `Mi si paneka.` ↔ `Mi si paniya.`. Глубокая варочная ёмкость не равна неглубокой жарочной.
7. **гостиная / ванная** (`salona` / `kamena`): `Mi bi na salona.` ↔ `Mi bi na kamena.`. Различные помещения по назначению.
8. **рубашка / футболка** (`silita` / `tisaleta`): `Mi si silita.` ↔ `Mi si tisaleta.`. Отличие формы и типа верхней одежды.
9. **библиотека / музей** (`libala` / `museo`): `Mi bi na libala.` ↔ `Mi bi na museo.`. Доступ к книжным фондам и экспонирование коллекций.
10. **автобус / поезд** (`busa` / `telena`): `Mi si busa.` ↔ `Mi si telena.`. Автодорожный и рельсовый транспорт.
11. **план курса / расписание** (`silabusa` / `timetala`): `Mi lita silabusa.` ↔ `Mi lita timetala.`. Содержание курса не является распределением занятий по времени.
12. **счёт / отчёт** (`pasala` / `lepota`): `Mi tami pasala.` ↔ `Mi tami lepota.`. Платёжное требование не равно описанию результатов.
13. **электронное / бумажное письмо** (`imeila` / `letela`): `Mi lita imeila.` ↔ `Mi lita letela.`. Канал доставки и форма сообщения.
14. **картина / фотография** (`pinetela` / `hotona`): `Mi si pinetela.` ↔ `Mi si hotona.`. Живописная техника и регистрация света.
15. **симптом / диагноз** (`simota` / `diyano`): `Meka tami simota.` ↔ `Meka tami diyano.`. Проявление болезни не тождественно заключению.
16. **судебное решение / апелляция** (`senatena` / `apela`): `Mi lita senatena.` ↔ `Mi lita apela.`. Акт разрешения дела не равен обращению на пересмотр.
17. **сайт / страница** (`webasita` / `webapana`): `Mi tami webasita.` ↔ `Mi tami webapana.`. Собрание страниц не равно одному документу.
18. **гипотеза / теория** (`hipotesa` / `teyolia`): `Mi tami hipotesa.` ↔ `Mi tami teyolia.`. Проверяемое предположение не равно развитой объяснительной системе.
19. **обнимать / целовать** (`seliwa` / `kisena`): `Mi seliwa yu.` ↔ `Mi kisena yu.`. Различные жесты внимания.
20. **доверять / бояться** (`ponila` / `tihena`): `Mi ponila yu.` ↔ `Mi tihena yu.`. Положительная оценка надёжности не равна страху.

**Граница доказательства:** CI проверяет формальную противопоставленность и наличие двух независимых смысловых описаний; человеческая интерпретация не измерялась.
