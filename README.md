# SAMA Encyclopedia 0.3

Полноширинная энциклопедия экспериментального международного языка SAMA. Проект на **TypeScript + HTML + CSS**, без React, базы данных и трекеров.

## Запуск на Windows (без установки зависимостей)

1. Распакуйте ZIP и откройте терминал в папке `sama-encyclopedia` (там, где `package.json`).
2. Нужен Node.js 20+ (рекомендуется 22).
3. Выполните `npm run start`.
4. Откройте `http://localhost:8080`.

Команда `start` запускает **готовую сборку `dist`** — не требует `npm install`.

## Разработка и проверки

```bash
npm install
npm run validate    # проверка слов, форм, статей, ссылок, примеров
npm run build       # компиляция TypeScript + отдельные статические HTML-страницы
npm test            # validate + build + HTTP smoke-test + route-test
npm run dev         # build и локальный сервер (без hot reload)
```

**Важно:** визуальная проверка в настоящем браузере не является частью автоматических тестов. `route-test` использует модель DOM и проверяет формирование страниц, а не вёрстку. Для выпуска на публичный хостинг дополнительно проверьте сайт вручную на компьютере и телефоне.

## Что есть

- 17 букв и звукарь с **приблизительным** синтезом речи браузера; реальных эталонных записей нет.
- 24 нормативно описанные главы. Функциональное разделение: внутренняя рабочая норма и экспериментальные расширения.
- 317 записей словаря: 43 рабочего ядра и 274 кандидата; архив 118 исключённых форм и протокол 18 конфликтов значений.
- 82 статьи, включая 58 учебных текстов предыдущей редакции, которые явно обозначены как архивные.
- 24 урока, 50 фраз, 36 вопросов тренажёра.
- 399 независимых HTML-страниц слов/статей (раздел `dist/pages`) + `dist/static-index.html`; такие страницы не требуют JavaScript и пригодны для поисковой индексации после публикации сайта.
- Поиск, фильтры по тематике и статусу, карточки слов, избранное, локальный прогресс, выгрузка CSV, мобильная навигация.

### Как добавить слово

Откройте `content/lexicon.json`, добавьте объект:

```json
{"w":"meya", "ru":"календарный месяц", "tag":"Время", "proposed":true, "status":"candidate"}
```

Выберите уникальное написание из 17 букв. Если это составная форма A-B, обе части должны существовать как самостоятельные слова. Не помечайте непроверенную лексему `core` без редакторской процедуры. После правки выполните `npm test` и перезапустите `npm run start`.

### Как добавить статью

Создайте файл `content/articles/<slug>.json` с полями `id`, `title`, `area`, `desc`, `paragraphs` и при необходимости `related`, `examples`, `status`, `edition`. Проверка `npm run validate` обнаруживает конфликтующие идентификаторы и битые ссылки на статьи.

## Публикация

Загрузите **содержимое папки `dist/`** на статический хостинг. Главная страница использует hash-маршруты (`#/...`), чтобы работать на обычном сервере без SPA-fallback. Для поисковых систем сформированы отдельные страницы в `dist/pages/`, индекс в `dist/static-index.html`.

## Ограничения

SAMA 0.3 не утверждён международной организацией и не исследован на выборке носителей разных родных языков. Старые статьи 0.1 могут противоречить рабочим правилам 0.3 — они выделены как архивные. Нет эталонных аудиозаписей, полного синтаксиса, стандарта календаря, переводчика и доказанной обучаемости. Не используйте SAMA для юридически/медицински критически важного перевода.

## Версия 0.4 — рабочий корпус 5000

`content/wordbank-5000.json` содержит ровно 5000 учётных словарных записей: 317 из редакции 0.3 и 4683 **автоматически образованных, не утверждённых** существительных. Их нельзя считать 5000 независимо проверенных слов. В проекте есть обзорная страница `#/wordbank` и индивидуальные карточки `#/proposal/forma`. Для воспроизводимого обновления выполните `python scripts/generate-wordbank.py`. Проверка качества выполняется командой `npm run validate`. Каждый кандидат получает морфемный разбор, проектную фонемную запись, прозрачное описание значения, пример и список нерешённых вопросов.


## GitHub Pages (публикация в репозитории richmanstudio/worldwidesamaianlanguage)

1. Администратор должен один раз открыть `Settings → Pages → Build and deployment → Source` и выбрать `GitHub Actions`. У существующей интеграции нет permission на `POST /repos/{owner}/{repo}/pages`, поэтому `actions/configure-pages` не может включить Pages самостоятельно (ошибка *Resource not accessible by integration*).
2. Перезапустить workflow тестовой страницы в GitHub Actions и **убедиться в HTTP 200 по публичному адресу** до замены тестового `index.html`.
3. Затем загрузить файлы исходного проекта в корень `main`. Workflow `.github/workflows/pages.yml` выполнит `npm install`, `npm test`, публикацию `dist/` через Pages.
4. Публичный адрес для проверки: https://richmanstudio.github.io/worldwidesamaianlanguage/

ВНИМАНИЕ: 5000 — число записей редакционного корпуса. НЕ 5000 утверждённых слов: новые 4683 являются автоматически собранными предположениями и по умолчанию исключены из учебного словаря.
