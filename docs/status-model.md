# R00-03 — Статусы языка SAMA

Ни один статус не означает международного признания. Разрешение менять статус не следует из запуска CI, количества слов или генерации текста.

| Статус | Смысл | В основной учебной норме? | Условия перехода |
|---|---|---|---|
| core | принято внутри рабочей версии с идентификатором | да, с пометкой «внутренняя норма» | менять только через версионированное решение и миграцию |
| candidate | авторский кандидат слова/правила | нет, только маркированный эксперимент | смыслы, примеры, отрицательные тесты, редактура → core |
| experimental | ограниченная проверяемая гипотеза | нет | проверка гипотезы и формальное решение → candidate/core |
| proposal | сырое, иногда сгенерированное предложение | нет | индивидуальная экспертиза → candidate |
| unresolved | открытая неопределённость или конфликт | нет | проект правила → experimental, не core |
| quarantine | исключённый конфликтный материал | нет | повторный аудит, новое решение и миграция |
| deprecated | старая норма, оставлена для обратной совместимости | нет | архивный редирект и неизменная история |
| rejected | отвергнуто обоснованным решением | нет | новое рассмотрение по новым данным |

## Поля отдельного решения

Указывать ID, версию, статус, форму или паттерн, точное значение, пример/контрпример, доказательства, reviewer (может быть null), конфликтующие источники и миграцию. Статус core в JSON 0.8 означает наследование и не создаёт второго независимого нормативного правила.

## Историческая разница схем

Существующие JSON используют поля level/status и не сводятся к одному формату. Этот документ — редакционная политика, а миграция всех форматов в схемы R01-05 / R09-01 ещё не выполнена.

Если нет внешних участников, human_review=false и external_validation=false; синтетическая проверка не заменяет независимый перевод.
