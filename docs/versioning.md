# R00-08 — Версии языка и сайта

Языковой стандарт и программная оболочка версионируются отдельно. В standard-release.json хранится действующая языковая редакция. Номер npm описывает программу и не доказывает завершённость языка.

MAJOR — несовместимое изменение формы, значения или синтаксиса. MINOR — принятые дополнения с сохранением старых значений; до 1.0 несовместимость допускается только с явной миграцией. PATCH — исправление описки без изменения значения. Новое слово получает дату и номер принятия; изменение значения получает новый sense-ID либо новую редакцию с описанием перехода.

Документы 0.3–0.9 являются историческими редакциями. Нормативная основа 0.11.0 — отдельная редакция принятого содержания; она не означает прохождения всех gates. Цель 1.0: полный согласованный стандарт, минимум 5000 принятых слов и синхронные учебные материалы. Публикация 1.0 требует отдельного manifest и go/no-go; факты внешних исследований отражаются отдельно и без переименования редакторских проверок в человеческие испытания.

История: docs/migration-log.md, docs/WORKLOG.md, Git commits. Старое правило не удаляется бесследно, а получает преемника.
