# R06-03 — Формальная семантика кванторов SAMA 0.16.0

Пусть D — заранее установленное дискурсом конечное множество лиц указанной именной группы, P(x) — истинность всего предиката для лица x. Парсер не знает, кто и что совершил; значения P предоставляются интерпретатору только для проверяемых примеров.

| SAMA | Логическая форма | Условие истинности |
|---|---|---|
| `Tawa N li P` | ∀x∈D P(x) | Все члены удовлетворяют P |
| `No tawa N li P` | ¬∀x∈D P(x) | Есть хотя бы один не удовлетворяющий P |
| `Tawa N li no P` | ∀x∈D ¬P(x) | Никто не удовлетворяет P |
| `Somi N li P` | ∃x∈D P(x) | Хотя бы один удовлетворяет P |
| `No somi N li P` | ¬∃x∈D P(x) | Ни один не удовлетворяет P |
| `Somi N li no P` | ∃x∈D ¬P(x) | Хотя бы один не удовлетворяет P |
| `Mowa N li P` | |{x∈D:P(x)}| > |D|/2 | Больше половины удовлетворяют P |
| `No mowa N li P` | ¬(count(P)>|D|/2) | Не больше половины удовлетворяют P |
| `Mowa N li no P` | count(¬P)>|D|/2 | Больше половины не удовлетворяют P |

**Пустой домен:** `tawa` и `mowa` требуют ненулевого числа участников, иначе имеют неопределённое значение (пресуппозиция непустоты); `somi` ложно и `no somi` истинно при D=∅. **Ровно половина** не является большинством. **Исключение:** `tawa N li sule X P` оценивается в D\{X}, если X — член D; ни P(X), ни ¬P(X) из фразы не следует. Если D\{X} пусто, универсальная оценка неопределённа.

Сравнение `Tawa ami li no wako.` и `No tawa ami li wako.` не сводится к перестановке нейтральных слов: границы истинности различаются. `tests/quantifier-scopes.json` даёт 40 пар в непустых конечных группах, где соседние высказывания имеют *разные* значения истинности. Кроме того, `scripts/quantifier-test.mjs` проверяет исключение одного участника, пустую группу, половину и большинство. Эти результаты не моделируют психологию усвоения языка.

**Предел:** модель оценивает лишь подлежащее с одним квантором и заранее известный полный предикат. Объектные/вложенные кванторы, источник факта, причинные утверждения, вероятностные оценки, номинальные исключения нескольких человек и реальная анафора не выведены из этих формул.
