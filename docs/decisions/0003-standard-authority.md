# ADR-0003 — Принятие стандарта SAMA по мандату владельца

Дата: 2026-11-22. R-ID: R00-03/06/08/11, R01-01, R07-17, R10-13. Статус: accepted-internal. Основание: владелец поручил создать утверждённый язык, минимум 5000 слов и учебный сайт; затем подтвердил выполнение словом «делай».

## Решение

Нормативность конструируемого языка устанавливается редакционным решением владельца или уполномоченного им редактора. Для текущего цикла подготовка, выбор и фиксация правил делегированы ИИ-редактору. Это позволяет принимать определённые формы и значения без вымышленного внешнего органа утверждения. У принятой единицы есть статус core, точная область, дата, решение, дефиниция и примеры. Прежний статус candidate не переносится автоматически.

Различаем три факта: правило принято как норма; его формальная согласованность проверена; его изучаемость измерена на людях. Ни один из них не заменяет другой. Авторские примеры не приписываются участникам исследования.

## Альтернативы

1. Бессрочно накапливать лабораторные варианты — не соответствует новому поручению.
2. Переименовать все 5000 прежних строк в утверждённые — сохраняет ошибочные определения и отвергнуто.
3. Выпускать явные нормативные редакции с ограниченным покрытием, расширяя их до полного 1.0 — принято.

## Последствия и миграция

Исторические файлы 0.3–0.9 и baseline остаются неизменяемыми свидетельствами прежних решений. Новая норма хранится отдельно: content/rules/core.json, content/lexicon-v1.json, content/phonology-v1.json. Новые страницы читают эти источники; прежние материалы доступны через архив. При противоречии действующая нормативная редакция имеет приоритет. Переход конкретного слова в core требует отдельной записи в новом словаре, не изменения legacy-статуса.

Целевой 1.0 требует минимум 5000 обработанных слов и завершённого содержания. Независимые исследования ведутся отдельно; отсутствие исследования не превращается в утверждение о лёгкости для всех. До выполнения приёмки полный релиз 1.0 не объявляется.

Подготовил: ИИ-редактор по мандату Данилы. Независимый рецензент: не назначен. Основание, результаты и ограничения публикуются в журнале.
