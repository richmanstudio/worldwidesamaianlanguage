# R00-05 — Реестр лингвистических и архитектурных решений

Решения нумеруются неизменяемыми ID. Новое решение отменяет старое явной ссылкой; история не стирается. Статус решения не заменяет статус языкового правила.

## Шаблон ADR

1. **ID, дата, R-ID, issue, версия.**
2. **Статус решения:** proposed / selected-for-pilot / accepted-internal / superseded / rejected. **Статус правила:** core / experimental / unresolved / deprecated.
3. **Проблема и источники:** точные пути, ID, исходные формы и значения.
4. **Альтернативы:** преимущества, недостатки, цена изменения.
5. **Выбор и область действия:** формальная схема, связывание, границы и исключения.
6. **Примеры и контрпримеры:** меняющийся смысл и ожидаемый отказ.
7. **Проверка:** тесты и результаты; авторская редактура отдельно от независимых данных.
8. **Миграция:** before/after, затронутые материалы, архивные копии и baseline drift.
9. **Последствия и нерешённое:** ограничения, зависимости, условия пересмотра.
10. **Ответственные:** кто подготовил, кто утвердил, кто независимо рецензировал. Отсутствующий участник — «не назначен / не проверено».
