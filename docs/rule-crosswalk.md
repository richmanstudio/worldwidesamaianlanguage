## Правило нормативного объединения

В машинном файле `content/rule-registry.json` каждой тематической группе назначен ID вида `SAMA-RULE/topic`. Если найден source=spec03 с core, он отмечен как **временная рабочая опора**, не как международно подтверждённый окончательный текст. Остальные записи получают только ссылку. Если источник 0.3 candidate либо отсутствует, нормативный текст **ещё не создан**.

Для завершения R00-04/R01-02 нужно редакционно сравнить смыслы каждой пары, выбрать единственный действующий текст правила, создать примеры/контрпримеры, устранить CF-001... и мигрировать учебник. Наличие этого crosswalk само по себе не закрывает G1.
