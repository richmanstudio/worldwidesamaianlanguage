## Правила обновления

- **Задачи закрываются только с доказательством** (commit / тест / отчёт / независимая проверка).
- В начале работы назначить R-ID; в конце обновить этот файл и `WORKLOG.md`.
- **Достижения релиза 0.9 не переименовывать в completed gates:** фонетика и 5 000 записей — исследовательские, международных испытаний нет.
- Факт `main` может измениться. Перед новым циклом проверять свежие JSON и SHA, а не полагаться на этот снимок.
