# R00-11 — Метрики готовности

Публикуются: число действующих rule-ID; число принятых слов с полной статьёй; покрытие коммуникативных задач; пройденные проверки; число открытых дефектов; реальные участники исследований. Значения старого 5000-строчного wordbank не включаются в число принятых слов автоматически.

Принятое слово содержит форму, произношение, часть речи, sense-ID, определение, примеры и решение принятия. Разные словоформы или случайные комбинации корней не считаются самостоятельными словами без собственной дефиниции. Число страниц и коммитов не преобразуется в процент готовности. Целевой словарь 1.0 — не менее 5000 таких статей.

Нормативное принятие, результат CI, независимое рецензирование и результаты людей — отдельные показатели. Слово «утверждено» означает принято в стандарте SAMA по полномочиям владельца; оно не означает международную сертификацию.
